
### Baseline Sample Results

This folder contains **sample outputs** of the isolation and baseline scripts.

You do **not** need to run the scripts to understand the expected results.

| File | Description |
|------|-------------|
| `sample-01-isolate.txt` | Example output of `01-isolate.sh` |
| `sample-02-baseline-jitter.txt` | Example output of a good zero-load baseline run |

These samples assume a reasonably well-isolated machine.
